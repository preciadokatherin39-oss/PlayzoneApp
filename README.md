# # Playzone - Sistema de Reserva de Canchas Deportivas
Proyecto Final - Programación 5

### Descripción
Playzone es una plataforma web para la consulta y reserva de canchas deportivas (Fútbol 5, Tenis y Baloncesto). 
El sistema contempla 3 roles con permisos diferenciados y está basado en 15 tablas relacionales.
